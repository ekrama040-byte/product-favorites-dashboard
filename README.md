# 🛍️ Responsive Product Favorites Dashboard

A modern, responsive product discovery dashboard built with **HTML, CSS, and vanilla JavaScript**.

The application fetches products dynamically from the **DummyJSON API**, allows users to search and sort products, and provides a favorites system that persists using `localStorage`.

Designed to provide a clean experience across **desktop, tablet, and mobile devices**.

---

## ✨ Features

- 🔎 **Product Search**
  - Search products dynamically using the DummyJSON API.
  - Search results update based on the user's query.

- ❤️ **Favorites**
  - Add products to favorites.
  - Remove products from favorites.
  - Favorites are persisted using browser `localStorage`.
  - Dedicated favorites page.

- 📱 **Fully Responsive**
  - Desktop layout
  - Laptop layout
  - Tablet layout
  - Mobile layout
  - Small-screen optimization

- ↕️ **Product Sorting**
  - Sort products based on available product information.

- ⚡ **Dynamic API Rendering**
  - Products are loaded from the API rather than hardcoded.
  - Loading states are displayed while fetching data.
  - Error states are handled gracefully.

- 🎨 **Modern UI**
  - Clean card-based product layout.
  - Responsive CSS Grid.
  - Responsive sidebar.
  - Favorite buttons beside products.
  - Mobile-friendly controls.
  - Hover and interaction states.

- 💾 **Local Storage**
  - Favorites remain available after refreshing the browser.
  - No backend database required.
